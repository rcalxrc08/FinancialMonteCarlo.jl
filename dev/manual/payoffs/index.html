Payoffs

A payoff struct holds the terms of a contract: maturity T and, depending on the contract, strike K, barriers and whether it is a call (isCall = true, the default) or a put.

Constructors check that maturities, strikes and barriers are positive.

How payoffs are evaluated

The generic payoff function maps the matrix of simulated paths to the vector of discounted payouts, one per path. Each family has a generic engine implementing it, so a concrete payoff only needs to describe its payout:

  • European payoffs look at the column of the paths at maturity and call payout(S_T, payoff);
  • path dependent payoffs (barriers, Asians) receive the whole path of each simulation;
  • American and Bermudan payoffs are priced with the Longstaff-Schwartz regression, using the exercise value payout(S_t, payoff) at every step (or exercise date).

Because the paths are shared, several payoffs with different maturities can be priced on the same simulation: the paths go up to the largest maturity and each payoff picks the time steps it needs. For this to be exact, maturities should fall on the time grid 0:T/Nstep:T.

Smiles

A smile groups European (or binary European) options with the same maturity and different strikes:

FinancialMonteCarlo.EuropeanOptionSmile(1.0, [90.0, 100.0, 110.0], [false, true, true])

pricer, variance, confinter, delta and rho return one value per strike, in the order of K. payoff returns a matrix with one row per path and one column per strike, and FinancialMonteCarlo.payout(ST, smile) the undiscounted payouts for one value of the underlying.

In CudaMode, pricer, variance, delta, rho and payoff return a CuArray, so what follows can run on the GPU too; use Array(prices) to read them on the CPU. confinter returns a Vector of tuples. With the strikes on the GPU too, implied volatilities need no transfer:

smile = FinancialMonteCarlo.EuropeanOptionSmile(T, CuArray(K), CuArray(isCall))
prices = pricer(model, rfCurve, MonteCarloConfiguration(Nsim, Nstep, FinancialMonteCarlo.CudaMode()), smile)
volatilities = blsimpv.(S0, smile.K, r, T, prices, d, smile.isCall) # FinancialToolbox
